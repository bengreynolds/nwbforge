# Custom Workflow Baseline

Purpose: capture the repo-owned custom-path conversion flow.

Current baseline:
- Custom sessions can be assembled from arbitrary supported files and folders
- The desktop flow builds a draft session and then writes through the shared pipeline
- Repository-owned custom examples remain a bootstrap and testing path

Constraints:
- Custom paths should not become a special ad hoc writer layer
- The custom path remains separate from supported NeuroConv routes
- Uncertain mappings should stay reviewable

Next step:
- Expand the custom path only when the dataset model needs more structure
